Accounting Ledger Application
Description:
A Java command-line application that tracks financial transactions using a CSV file.
Features:
1- Add Deposits
2- Add Payments
3- View All Transactions
4- Filter Deposits
5- Filter Payments
6- Month To Date Report
7- Previous Month Report
8- Year To Date Report
9- Previous Year Report
10- Search By Vendor

Technologies Used:
1- Java
2- IntelliJ IDEA 
3- Git
4- GitHub

How To Run:
1- Open the project in IntelliJ IDEA
2- Run Main.java
3- Use the menu options to manage transactions.

Interesting Code:
I used a reverse loop display the newest transactions first:

for(int i = transactions.sixe()) - 1; i >= 0; --i) {
system.out.println(transactions.get(i));
}
This allowed me to satisfy the project requirement that ledger entries display newest first
